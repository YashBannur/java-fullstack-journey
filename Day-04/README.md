## 📝 Key Concepts Learned

### Inheritance

* Child classes can inherit properties and methods from parent classes.
* `extends` keyword is used for inheritance.
* Promotes code reusability.

### Method Overloading

* Same method name with different parameters.
* Example of Compile-Time Polymorphism.

### Method Overriding

* Child class provides its own implementation of a parent class method.
* Example of Run-Time Polymorphism.

### Polymorphism

* One interface, multiple forms.
* Compile-Time Polymorphism → Method Overloading.
* Run-Time Polymorphism → Method Overriding.

### Binary Search

* Efficient searching algorithm.
* Works only on sorted arrays.
* Time Complexity: O(log n).

### Bubble Sort

* Compares adjacent elements and swaps them if necessary.
* Largest element moves to the end in each pass.
* Time Complexity: O(n²).
