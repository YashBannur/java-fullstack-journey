## 📝 Key Concepts Learned

### Static Keyword

* Belongs to the class rather than an object.
* Shared among all objects of a class.
* Helps save memory when data is common.

### Static Variables

* Only one copy exists.
* Shared by all objects.
* Useful for counters and common information.

### Static Methods

* Can be called using the class name.
* Do not require object creation.
* Can access only static members directly.

### Final Keyword

* Used to make values constant.
* Prevents reassignment.
* Can be applied to variables, methods, and classes.
