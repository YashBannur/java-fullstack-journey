## 📝 Concepts Learned

### Constructors
- Special methods used to initialize objects
- Automatically called when an object is created
- Constructor name must match the class name

### Constructor Overloading
- Multiple constructors in the same class
- Different parameter lists
- Allows creating objects in different ways

### `this` Keyword
- Refers to the current object
- Resolves ambiguity between instance variables and parameters
- Can be used for constructor chaining

### HTML Tables
- Creating rows and columns using `<table>`, `<tr>`, `<td>`, and `<th>`
- Organizing timetable data effectively

### Semantic Tags
- `<header>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

### Inline vs Block Elements
- Inline Elements: `span`, `a`, `strong`
- Block Elements: `div`, `p`, `h1`, `section`
